# 路线图

依据产品蓝图 v0.2。北极星指标：**同类错误复发率**（某个错因第一次出现后，之后的复盘里再出现的比例）。

## 已完成（v0.3，2026-10-27）

- 三份众测实现择优合并为独立仓库，只保留雅思模块（详见 [ielts/ARCHITECTURE.md](ielts/ARCHITECTURE.md) 末节）。
- 修复：英文写全的数字（`three hundred and twenty`）按一个数字计。
- P0-1 录入提速：题集库（同一篇只录一次）+ 一行答案速记。
- P0-2 归因：错题不等模型就能选错因；用户的选择不被模型覆盖；听力快捷标签；错因表新增“定位丢失 / 读题失误 / 主语追踪”。
- 北极星指标上线：错题页“同类错误复发率”表、MCP `weakness`。
- 本地 MCP 引擎（零依赖）+ `ielts-review` 技能：订阅路线下宿主模型识别照片、引擎校验和判题。
- 数据备份：导出后可从文件恢复（API key 不导出、也不会被导入）。

## 已完成（v0.4，2026-10-27）

- 录入减成三个框，答案册和自己的答案一个框；题目说明行自动带出题型和字数要求；原文可不填。
- 讲题从用户做题时的处境讲起，替换机制和证据强度、不确定之处、难词；真正的多轮追问。
- 复盘报告：三张表，复制 / 导出 Markdown、CSV。
- 做题方法板块：内置平行阅读法，可编辑、可自建；执行指标与趋势分析。
- 拼写听写（浏览器语音）。
- MCP：`answer_sheet` 录入、原文/答案来源标记、讲解新字段与“证据不完整必须写 uncertainty”、`report`、`method`。

## 下一步

0. **考完试后**：把作者的研究心得作为设计原则迁移进来（方法、讲题原则、指标）。
1. **自己当第一个用户**：用剑 19、20 全部走一遍复盘，积累真实错误数据。这是验证一切的前提。
2. **P0-3 针对错因的复练**：按错因出专项题，而不是重做原题——同义替换识别题、FALSE/NOT GIVEN 判别、基于自己错词的听写、只标定位句不答题。
3. **MCP Apps 界面**：把录入核对卡、讲解卡、弱点面板做成 HTML 组件挂到 MCP Apps；不支持界面的宿主自动退回纯文字。
4. **网页版 ↔ MCP 数据互通**：网页版导出文件与 MCP 数据文件夹格式对齐，可以双向导入。
5. **讲解缓存与成本提示**：同一题的讲解本地缓存；调用前显示预估 token。
6. **P1**：口语母故事系统、Part 3 闭合话题库、写作“保留框架只改语言”与个人表达库、机经整理器。

## 明确不做

| 不做 | 原因 |
|---|---|
| 站内考试界面、自建题库 | 不是要解决的问题，而且碰版权 |
| 自研语音识别 | 输入法转写已经够用 |
| 一键范文、整篇代写 | 违背训练目标 |
| 社交、排行榜 | 和复发率无关 |
| 平台统一的模型 key | 成本和滥用风险都由平台承担，自带 key / 订阅更可持续 |
