# 整套复盘、间隔复习与模型审计

## 同一套题归组

阅读按 3 个 Passage、听力按 4 个 Part 归套。

1. 来源标签先转为系列键：忽略大小写和连续空白，并把 `Passage 3` / `Part 2` 的编号替换为占位符。
2. 同一模块、同一系列键的记录进入一套。来源标签必须由用户保持一致；系统不根据题目内容猜测套题。
3. 每个 Passage/Part 取最近一次复盘。阅读要求 Part 1–3，听力要求 Part 1–4；缺少任一部分即显示“未完整”，不补造记录、不估分。
4. 整套用时只累加用户实际填写的 `elapsedSeconds`。没有记录显示“未记录”，不根据题量或计时器状态估算。
5. 各部分正确率 = 该部分正确题数 / 该部分题数。
6. 只有整套完整、总题数为 37–40 时才调用公开分数接口估算 Band。阅读当前统一按 Academic Reading 估算；General Training 需要后续显式选择考试类型，不在本版猜用。

## 报告

- 页面：`/ielts/sets`。
- 可导出 Markdown：来源、完整状态、已记录用时、各部分正确率、错因、估算 Band 与跨套变化。
- 导出内容不包含全文、API key 或模型输入。
- “打印报告”使用浏览器打印；`@media print` 隐藏全站 TopBar、侧栏、移动底栏、背景和操作按钮，并解除应用固定高度，报告按纸张分页。

## 间隔复习规则

复习对象：

- IELTS 错题记录（按错因分组）。
- “我的替换库”中的每一对同义替换。
- 收藏的词块（内置与自定义都适用；未收藏词块不进入队列）。

状态保存在 `irl-ielts-review-schedule`，每个对象键为 `kind:sourceId`，只保存排期和评分历史，不复制原文全文。

### 间隔

`[1, 3, 7, 14, 30]` 天，以完成复习当天的本地日历日期为起点，不从旧到期日叠加。

### 评分

- `again`（忘了）：`stage=0`，lapses +1，1 天后复习。
- `hard`（模糊）：stage 不变，按当前阶段间隔复习。
- `good`（记住）：stage +1（最多 5），按新阶段间隔复习；stage 1/2/3/4/5 分别对应 1/3/7/14/30 天。
- `easy`（很熟）：stage +2（最多 5），按新阶段间隔复习。

新错题、新替换和新收藏词块默认今天到期。复习后进入 upcoming，按到期日排序。删除错题/替换/取消收藏后，旧排期记录不会显示；当前版本不做跨设备同步。

### 今日队列

入口页和 `/ielts/review` 显示今天到期的错题、替换与词块。错题再按固定错因表分组，形成“错因复练计划”；所有答案默认隐藏，用户回忆后点击“显示答案”再评分。

## 模型调用审计

每次真实浏览器/代理模型调用（包括重试）写入 `irl-ielts-model-audit`，最多保留 100 条。记录：

- 调用 id、时间、模板 id、模板版本、服务商、模型名、传输方式。
- attempt、耗时、状态、HTTP 状态、错误码。
- 经过结构校验的模型输出；不可解析时只保存最多 600 字符的截断片段。
- 结构校验错误、变量字符数（只记长度，不记值）。
- `verifyEvidence` 的 `ok` 和缺失条数。

不记录：

- API key、Authorization header。
- 系统提示词、用户原文/文稿全文、题目输入全文。
- 任何可恢复完整原文的输入副本。

输出字符串单条最多 600 字符，数组最多 30 项，对象最多 40 个字段。疑似 `sk-...` 字符串会替换为 `[redacted-key]`。模拟反馈不调用模型服务，因此不写入模型日志。

设置页可以一键导出复现包 JSON，包含脱敏调用记录、涉及模板的 id/版本/变量名/约束/输出结构、当前模板版本与隐私声明。复现时使用用户自己的固定夹具重新运行；复现包不包含密钥或原文。

## 模板版本离线检查

`npm run ielts:check-template-versions` 使用固定原创样例验证：

- `ielts.reading.explain@1.0.0` 的 fixture 满足 v1 输出结构。
- `ielts.reading.explain@1.1.0` 的 fixture 满足当前结构（新增 `causeBasis`）。
- 两版所有引用都逐字出现在固定原文中并通过 `verifyEvidence`。

该检查不访问网络，并已接入 CI。
